# Planet Texture Assets

This directory serves as the root path for high-quality Surface Albedo Maps for our spherical celestial simulations.

To provide assets, please download equirectangular projections in JPEG or PNG formats, dropping them inside this folder. A recommended resolution is 2048x1024 or 4096x2048 for high fidelity.

### Target Files Expected:
* `sun.jpg`
* `mercury.jpg`
* `venus.jpg`
* `earth.jpg`
* `moon.jpg`
* `mars.jpg`
* `jupiter.jpg`
* `saturn.jpg`
* `uranus.jpg`
* `neptune.jpg`

_Note: The renderer will safely fallback to a pure white map alongside existing Phong colour tints if specific assets cannot be found here._

### Trusted Sources
We recommend downloading maps from **Solar System Scope (CC BY 4.0)** or **NASA Visible Earth (Public Domain)** open-source astronomical projects.
